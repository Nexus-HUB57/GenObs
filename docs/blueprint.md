# **App Name**: Nexus GenObs

## Core Features:

- Multi-language Code Generation: Generate high-quality code snippets and full functions in Python, Java, C++, and TypeScript using local Ollama models for complete privacy.
- Semantic Vault Discovery: Utilize a local HNSW index as a tool to perform high-dimensional semantic searches across vault notes and repositories for intelligent information retrieval.
- Deep Repository Auditing: An advanced analysis feature that acts as a tool to audit local codebases, identifying architectural patterns and recommending potential performance optimizations.
- Sandboxed Shell Execution: Securely execute Python code within a local isolated sandbox to validate logic, run scripts, or automate repetitive development tasks safely.
- Obsidian Native Interface: A seamless integration into the Obsidian sidebar and Command Palette, providing a cohesive workspace for developer agent workflows.
- TypeScript Plugin Bridge: A specialized integration layer using the Obsidian API to facilitate data sharing and event triggers between the agent and other community plugins.

## Style Guidelines:

- Primary color: Vibrant Indigo (#7C3AED) to evoke a professional and advanced technical aesthetic.
- Background: Deep violet-charcoal (#0B0A0F) optimized for Obsidian's dark workspace and long-duration eye comfort.
- Accent: Sky-blue (#70E0FF) used for highlighting code syntax, interactive elements, and path connections.
- Headlines: 'Space Grotesk' for a futuristic, geometric, and technical feel.
- Body Text: 'Inter' for high legibility and a clean, modern look during extended auditing sessions.
- An airy, modular grid-based layout that prioritizes a 'dashboard-first' view within the Obsidian pane.
- Minimalist line-based icons with thin weights and soft rounding for a sleek, modern IDE finish.
- Smooth, subtle transitions for code generation streaming and HNSW search result population.
