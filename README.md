# GenObs
Agentic AI

**Agentic AI Assistant para Obsidian**

Um agente inteligente completo integrado ao Obsidian: Daily Notes automáticas, geração de conteúdo com IA, busca semântica (embeddings), templates avançados, integração com Dataview/Templater e CLI.

**O assistente inteligente definitivo dentro do Obsidian.**

## Funcionalidades

- Daily Notes automáticas com reflexões geradas por IA (Ollama)
- Geração de texto com Llama 3.2 / Llama 4
- Integração com Dataview e Templater
- Configurações avançadas
- Ribbon icon + Command Palette

## Como usar

1. Instale o Ollama e rode `./setup-ollama.sh`
2. Coloque a pasta em `.obsidian/plugins/genobs/`
3. Ative o plugin no Obsidian
4. Use o ícone na barra lateral ou comando `GenObs`

## Tecnologias

- Ollama (local)
- TypeScript + Obsidian API
- Integração com plugins populares
